2Hole 1 — the date range went straight into SQL

The legacy query interpolates the caller's range. A string that closes the quote is treated as SQL instead of as a date. Two orders exist in the database — one in January, one in February — and the payload asks for January only.

Legacy — interpolation

SELECT id, customer, status, subtotal, tax_rate, discount
  FROM orders
 WHERE created_at >= '$from'
   AND created_at <= '$to'
 ORDER BY created_at ASC, id ASC

Refactor — prepared statement

SELECT id, customer, status, subtotal, tax_rate, discount
  FROM orders
 WHERE created_at >= :from
   AND created_at <= :to
 ORDER BY created_at ASC, id ASC
$stmt->execute([
    'from' => $this->parseDate('from', $from)->format('Y-m-d'),
    'to'   => $this->parseDate('to', $to)->format('Y-m-d'),
]);
Payload used as from: 2024-01-01' OR '1'='1

3Hole 2 — customer text rendered as markup

The legacy table concatenates the customer name into HTML. A customer named like a tag becomes a tag in the browser. Both fragments below are printed as source text, escaped for display — this page never inserts the raw payload as markup.

The <img> reaches the browser as an element. The onerror attribute then runs script.

HtmlRenderer::render()
